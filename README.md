파이썬, 딕셔너리 구조
본 코드는 3가지 기능, 7가지 모듈, 5가지 예외처리, 영속성에 중점을 두었다.
mod07에 데이터를 불러오기 위한, 파일 경로를 지정 및 파일 생성을 해야한다.
7가지 모듈로 기능을 구현하였기에 추후 유지보수 및 수정, 개편 등 유동적으로 사용이 가능하다.

• FR-1 : 데이터 등록 및 저장
• FR-2 : 데이터 분석 및 출력
• FR-3 : 데이터 수정

• MOD1 : CLI 메뉴 화면 출력 및 메뉴 선택 관리
• MOD2 : 입력된 데이타의 타입, 유효 범위, 필수값 유무 검증
• MOD3 : 닥셔너리 생성 후 등록 및 저장 (FR-1)
• MOD4 : 수정 값 수집 및 경신 처리 (FR-3)
• MOD5 : 지정된 구간 슬라이싱 및 연산 (FR-2)
• MOD6 : 메모라 내 전적 데이터 리스트 CRUD 관리
• MOD7 : 파일 읽기/쓰기 동기화 (영속성)

• EH-01 (잘못된 입력) : 정해진 타입과 다른 값을 입력한 경우
• EH-02 (데이터 부재) : 조회할 데이터가 존재하지 않을 경우
• EH-03 (필수 입력값 누락) : 사용자가 입력하지 않았을 경우
• EH-04 (중복된 데이터 등록) : 모든 데이터가 동일하게 입력한 경우
• EH-05 (유효 범위 초과) : 숫자를 입력했으나 게임 규칙상 불가능한 값이 들어온 경무

실행시 mod01이 실행되며, mod07로부터 데이터를 받아 메인 UI가 실행된다.
이때 사용자는 UI에 맞춰 1~4를 기입해 각각의 FR-1 ~ FR-3의 기능을 수행 할 수 있다.
요약하자면, 1은 등록, 2는 분석, 3은 수정, 4는 프로그램 종료다.

메인 화면에서 1을 입력 mod03가 실행, FR-1을 수행한다.
양식에 맞춰, 날짜인 yyyy-mm-dd hh:mm 입력 한다. 이것은 식별자로 사용하니 유의한다.
추후 등수, 캐릭명, 무기명, 총 피해량, K, D, A를 입력한다.
데이터는 mod06에 임시 저장되며 문자열, 정수열이 맞는지 mod02에서 검수 후 저장 완료시 mod07에 보내 지정경로에 저장한다.
사용자가 수정하지 않았을경우 기본 경로는 "C:\python\matches.txt" 이다.

메인 화면에서 2를 입력 mod05가 실행, FR-2를 수행한다.
추가 입력란이 나온다. 각각 1. 전체 분석  2. 이름/무기 검색  3. 이름/무기 최근 N판 (슬라이싱)을 담당한다.
1을 입력, mod07에 저장된 모든 전적을 평균내어 출력한다.
2를 입력, 사용자가 추가 입력한 캐릭명, 무기명에 맞추어 평균을 내어 출력한다.
3을 입력, 사용자가 추가 입력한 캐릭명, 무기명에 추가로 정수N을 입력하면 이름과 무기에 맞추어 최근 N판을 평균을 내어 출력한다.

메인 화면에서 3을 입력 mod04가 실행, FR-3을 수행한다.
전적 수정을 하기 위해선, 어떤 전적인지 알아야 하므로 식별자인 날짜를 입력, 수정할 전적의 yyyy-mm-dd hh:mm 입력한다.
(사용자가 의도하지 않는한, 날짜가 겹치는 것은 불가능하다. 만약 등록시 동등한 날짜를 입력하면 예외처리 EH-04가 출력된다.)
후 수정할 데이터를 번호에 맞춰 입력후 수정하면 된다.
한번에 하나의 데이터만 수정이 가능하다.

메인 화면에서 4를 입력 mod01에서 mod07을 실행해 저장 한다.
후 break를 실행하여 프로그램을 종료한다.
